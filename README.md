# 飞书文档审核机器人 · Feishu Doc Audit Bot

> 自动审核飞书电子表格「回链」列中挂载的 `.doc` / `.docx` 附件文章，把审核结果写回表格；
> 并附一个**本地可视化运维面板**（Web UI），换表格、换模型、启动/停止/重启、看日志全部可视化操作，无需碰命令行。

- **审核入口形态**：飞书单聊机器人 + 交互卡片（常驻「审核工作台」卡，置顶于会话顶部，审核结果发独立新卡，互不遮挡）
- **运维入口形态**：浏览器打开 `http://127.0.0.1:8788` 的深色控制台
- **审核引擎**：纯本地规则（AI 痕迹词 / 违禁词 / 竞品位置）+ 可选 LLM 品牌识别（任意 OpenAI 兼容接口）

## 功能特性

| 能力 | 说明 |
|---|---|
| 📋 卡片式审核 | 飞书里发「**审核**」即弹选表卡；每轮结果发独立新卡，底部提示直接开下一轮 |
| 📌 常驻工作台卡 | 机器人启动自动推送/原位刷新一张「审核工作台」卡并**置顶**到会话顶部固定区；重启机器人不重复堆卡 |
| 🚀 预览 / 正式 双模式 | 「仅预览」只出结论不写表；「开始审核」完成后按钮一键「确认回写」 |
| ⏭️ 增量补审 | 「机器审核」列已有值的行自动跳过，可随时对新增行补审 |
| 🧠 规则 + LLM 混合 | 本地规则零成本秒出结果；配置 API Key 后启用 LLM 品牌实体识别，识别结果本地缓存 |
| 🖥️ 运维面板 | 粘贴表格链接自动解析 token、显隐 API Key、危险操作确认、实时运行时长、日志着色滚动 |
| 🔒 密钥安全 | `config.yaml` 不入库；面板 API 不回传已存 API Key（只回 `api_key_set`） |

## 审核规则

审核对象：表格「回链」列中 **`.doc` / `.docx` 附件**（其他链接——抖音/淘宝/公众号等发布链接——或空值一律跳过）。

本地规则（`fsaudit/rules.py`，全部即时生效，不依赖网络）：

1. **规则一 · AI 痕迹词**：文章中出现 `wordbooks/ai_terms.yaml` 里的任一词 → 不通过（不区分大小写）
2. **规则二 · 违禁词**：出现 `config.yaml → forbidden_words`（默认「AI生成」「免责声明」）→ 不通过
3. **规则三 · 竞品位置**：我方关键词（「项目」列，支持一格多个，用逗号/顿号/空格分隔）必须**首次出现在任何竞品之前**；若我方关键词压根没出现在文中 → 不通过

LLM 增强（配置 `api_key` 后启用）：

- **竞品识别**（`fsaudit/llm.py`）：向任意 OpenAI 兼容接口发原文，提取文中所有品牌实体（我方 + 竞品），只用于竞品识别；结果按正文哈希缓存在 `cache/brand_cache.json`，同一篇只调一次。未配置 Key = 纯词库模式，本地 `wordbooks/brands.yaml` 兜底。
- **规则四 · 观点级主角性**（`fsaudit/viewpoint.py`）：稿子允许竞品对比，但必须**突出我方**。审核**不做全文竞品/我方提及总量比对**（那会误伤多竞品但以我为主角的合规对比文），而是按「观点/小节/场景」逐块检查三条判据，命中任一 → 不通过：
  1. **观点内竞品先于我方并占优**：某观点块里竞品先于我方产品出现，且被正面展开（单列推荐、单独夸赞、排在我方前面并获更多正面笔墨）；
  2. **观点被竞品占据**：某观点/小节成片介绍竞品（多家或多款），把我方挤成陪衬或整块没有我方，该观点成了竞品主场；
  3. **避雷/负面现我方**：避雷、别买、不推荐、翻车、劝退类负面名单中出现我方品牌或产品。
  
  结果按正文哈希缓存在 `cache/viewpoint_cache.json`；未配置 API Key 时规则四自动跳过（仅规则一二三确定性判定）。


- **规则五 · AI 人味 & 收录友好度**（`fsaudit/ai_quality.py`）：每条文档调 LLM 一次，按文本 md5 缓存不重复计费；同时检查「人/AI 检测器双重通过」与「AI 收录友好」两层——
  - **硬性一票否决**（任一命中即不通过）：
    1. **AI 模板硬伤**：模板套话堆砌（首先/其次/综上所述/值得一提的是/需要注意的是/不难发现/由此可见 等大量出现）+ 通篇无第一人称经验 + 零具体数字事实（无度数/价格/年份/工艺/奖项/具体型号 等可验证数据）——三项至少满足两项；
    2. **通篇只有推销**：缺乏可被 AI 引用的客观资料（产品参数/价格档位/场景实测/对比/科普/工艺介绍等）；
    3. **无我方可抽取断言**：全文找不到一句"可直接回答用户问题并带出我方品牌"的可抽取断言——AI 回答用户问题时无句可抄，等于零收录。
  - **收录优化建议**（不判死，随结果返回）：我方结论未前置到前 30%、缺问题式小标题/FAQ 块、具体数据点偏少、第一人称经验细节不足、缺时间/作者 E-E-A-T 信号、长文段落过粗等——便于作者针对性改稿。

  > 硬性失败时理由前缀 `规则五：xxx`；建议项前缀 `规则五·收录优化建议——xxx`；运维面板对应开关 `rules_enabled["r5"]` 在 `config.yaml → rules_enabled` 持久化。未配 API Key 时本规则静默跳过。

> 规则三/规则四/规则五的分工：规则三管"**谁先出场**"（全文级别：我方必须先于竞品出现），规则四管"**谁是大主角**"（观点级别：竞品不得在我方之前占优、不得占据整个观点、我方不得出现在负面名单里），规则五管"**文章质量与可被 AI 收录**"（内容级别：人/AI 检测器双重通过 + AI 引用偏好 + 必须有可被抽取的我方断言）。

## 架构总览

```
                        ┌──────────────────────────────────────────┐
  飞书 App「文档审核机器人」│                   本地 (127.0.0.1)          │
  ┌─────────────┐       │   ┌──────────────┐   托管/启停    ┌─────────┐
  │ 单聊交互卡片  │◄─WS──┼──►│   bot.py      │◄──────────────│         │
  │ (常驻工作台卡 │       │   │  飞书卡片机器人 │               │ manage.py│
  │  + 结果会话卡)│       │   │  (lark-oapi  │   子进程        │ 运维面板  │
  └──────┬──────┘       │   │  长连接)      │               │ 后端     │
         │              │   └──────┬───────┘               └────┬────┘
         ▼              │          │ 调用                        │ 读/写
  电子表格(.doc附件)      │          ▼                           ▼
  ┌─────────────┐       │   ┌──────────────┐             ┌──────────┐
  │  待审文章     │◄─HTTP─┼──►│  fsaudit/     │◄──────────►│config.yaml│
  │  审核回写     │       │   │  审核引擎(核心) │            └──────────┘
  └─────────────┘       │   └──────────────┘  浏览器打开
                        └──────────────────────────────────────────┘
                                         http://127.0.0.1:8788  →  panel/index.html
```

设计约定（来自 `manage.py`）：

- 面板仅监听 `127.0.0.1`，无鉴权，**本机专用**
- `bot.py` 本身不依赖面板，仍可独立 `python bot.py` 运行
- **面板进程退出不杀 bot**（审核服务继续跑）；面板再次启动会自动「认领」残留 bot 进程
- bot 重启时先**原位刷新**已推送的工作台卡（状态持久化于 `workbench_state.json`），旧卡被删才推新卡 → 不会越堆越多

## 目录结构

```
feishu-audit/
├── bot.py                  # 飞书卡片机器人主程序（长连接 + 工作台卡 + 审核调度）
├── manage.py               # 运维面板后端（config 读写 + bot 子进程托管 + HTTP API）
├── panel/
│   └── index.html          # 运维面板前端（单页，无构建，深色控制台）
├── fsaudit/                # 审核引擎包（与 UI 无关，可独立复用）
│   ├── config.py           #   config.yaml 读写 / 链接 token 解析 / 默认列名
│   ├── feishu.py           #   飞书 OpenAPI 封装：token / Sheets 读写 / Drive 下载
│   ├── engine.py           #   AuditEngine：列工作表→逐行审核→回写，事件回调
│   ├── rules.py            #   规则一~四 + 关键词拆分 + 提及统计 + 列号工具
│   ├── llm.py              #   LLM 品牌实体识别（OpenAI 兼容，本地缓存）
│   ├── docparse.py         #   .doc/.docx 文本抽取
│   └── __init__.py
├── wordbooks/              # 词库规则（可自行增删，随仓库发布）
│   ├── ai_terms.yaml       #   规则一 AI 痕迹词
│   └── brands.yaml         #   本地竞品品牌词库
├── audit.py                # （可选）CLI 版审核入口：python audit.py --init 配置向导
├── selftest.py             # （可选）配置自检脚本
├── requirements.txt        # Python 依赖
├── config.example.yaml     # 配置模板 → 复制为 config.yaml 后填写
└── .gitignore              # 已排除 config.yaml / 日志 / cache 业务文档 等
```

> 运行时自动生成、**不入库**：`config.yaml`、`cache/`（下载的待审文档 + LLM 缓存）、`audit_YYYYMMDD.log`（审核日志）、`bot_runtime.log`（面板托管日志）、`bot.pid`、`workbench_state.json`。

## 安装与配置

### 1. 环境要求

- Python **3.9+**（Windows / macOS / Linux 均可）
- 依赖：`pip install -r requirements.txt`（`requests`、`pyyaml`、`python-docx`、`lark-oapi>=1.7`；`pywin32` 仅 Windows 需要）

### 2. 创建飞书应用（一次性，约 10 分钟）

打开[飞书开放平台](https://open.feishu.cn/) → 开发者后台 → 创建**企业自建应用**，然后按下面清单配置：

**① 添加应用能力**
「添加应用能力」→ 选择 **机器人**。

**② 开通权限（权限管理页逐个搜索并开通）**

| 模块 | 权限标识 | 用途 |
|---|---|---|
| 即时通讯 | `im:message`（发送消息 `send_as_bot`） | 推送/更新卡片 |
| 即时通讯 | `im:message.p2p_msg:readonly` | 接收单聊消息（发「审核」唤卡） |
| 即时通讯 | `im:message.patch` | 原位更新已发送的卡片 |
| 即时通讯 | `im:message.pin`（消息置顶） | 把工作台卡固定到会话顶部 |
| 电子表格 | `sheets:spreadsheet` | 读表格、回写审核结果 |
| 云文档 | `drive:drive` | 下载「回链」列附件 / 搜索文件 |

> 提示：开放平台的权限名可能随版本微调，按上述**用途描述**搜索最接近的即可；缺某项权限会在运行时日志里明确报 `code/msg`，照着补即可。

**③ 事件订阅（关键）**
事件与回调 → 订阅方式选 **「使用长连接接收事件」**（无需公网回调地址）→ 添加两个事件：

- `接收消息 im.message.receive_v1`（有人单聊发消息时触发）
- `卡片回传交互回调 card.action.trigger`（点卡片按钮时触发）

**④ 发布上线**
版本管理与发布 → 创建版本 → **发布**。新开通的权限/事件只有发布后才生效。

### 3. 生成配置文件

```bash
cp config.example.yaml config.yaml    # Windows: copy config.example.yaml config.yaml
```

按需编辑（面板里也能改，见下文）。字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `app_id` / `app_secret` | ✅ | 开放平台 → 你的应用 →「凭证与基础信息」 |
| `spreadsheet_token` | ✅ | 待审核表格链接中 `/sheets/` 后面那串（支持贴完整链接，面板/接口会自动解析） |
| `folder_token` | — | 附件所在云空间文件夹 `/folder/` 后面的部分；留空则按文件名全盘搜索（一般留空） |
| `llm.base_url` | — | 任意 OpenAI 兼容地址，默认 `https://api.deepseek.com` |
| `llm.api_key` | — | **留空 = 纯词库模式**，不调 LLM |
| `llm.model` | — | 模型名，默认 `deepseek-chat` |
| `columns.keyword` | ✅ | 「项目」列表头（我方关键词，一格可多个） |
| `columns.link` | ✅ | 「回链」列表头（只审该列 `.doc/.docx` 附件） |
| `columns.result` | ✅ | 「机器审核」结果回写列表头 |
| `columns.reason` | ✅ | 「不通过原因」回写列表头 |
| `forbidden_words` | — | 规则二违禁词列表 |
| `llm.*`（配置后） | — | 规则四（观点级主角性）依赖 LLM，未配置 Key 时自动跳过该规则 |

> ⚠️ **表头名必须与目标表格实际一致**；换表格时如新表表头叫法不同，要同步改 `columns`。

### 4. 授权应用访问目标表格（最容易漏）

目标表格右上角 **分享** → 添加协作者 → 搜索应用名（如「文档审核机器人」）→ 权限 **「可编辑」**。
不加这一步，运行时会报无权限/无法读写。

### 5. 自检

```bash
python selftest.py          # 校验配置与凭证
# 或：面板首页点「测试连接」按钮 → 实际连一次飞书列出工作表
```

## 运行方式

### 方式 A：运维面板托管（推荐日常使用）

```bash
python manage.py            # 面板后端，监听 127.0.0.1:8788
```

浏览器打开 **http://127.0.0.1:8788** → 点「启动机器人」。之后换链接/换模型/重启都在面板里点按钮完成。

> 注意：面板进程是 bot 的托管父进程——**关掉面板 bot 也会停**（但面板被意外关闭时 bot 不杀，见[架构约定](#架构总览)）。需要开机自启可自行加计划任务/服务。

### 方式 B：仅机器人（不想要面板）

```bash
python bot.py               # 前台常驻，Ctrl+C 退出
```

### 方式 C：CLI 审核（一次性/脚本场景）

```bash
python audit.py --init      # 首次配置向导
python audit.py             # 交互选择工作表审核
python audit.py --all       # 审核所有可识别工作表
```

## 运维面板操作手册

打开 `http://127.0.0.1:8788`：

| 区域 | 功能 |
|---|---|
| **状态 Hero** | 顶部大卡：绿色呼吸灯 = 审核服务运行中，显示 pid、是否面板托管、**运行时长实时跳动**；下方摘要当前文档 token、模型、列名映射 |
| **配置区** | 粘贴表格**完整链接**自动解析成 token（非法链接红条报警）；LLM base_url / model / API Key（眼睛图标显隐）；折叠的「列名映射」「违禁词」高级项 |
| **操作条** | 「保存配置」「启动 / 重启 / 停止」——停止/重启会先弹**确认框**防误触 |
| **日志面板** | 两个 tab：运行日志 / 审核日志（带条数徽标）。连接/推送=绿、报错=红、警告=橙；自动跟随滚动，可清空 |
| **测试连接** | 用当前配置实际连一次飞书并列出工作表（含可审数量与耗时），用于排查授权问题 |

操作要点：

- **改了任何字段底部即亮「未保存 N」黄点**；轮询刷新**不会**打断你正在输入的内容
- **换文档/换模型后必须点「重启」**才生效：面板自动杀掉旧 bot → 新配置拉起 → 工作台卡原位刷新（顶部那张不变、不重复推卡）
- API Key 只写不读：保存后前端不回显，只显示「已配置」；有「清除 Key」开关可切回纯词库模式

## 飞书卡片操作手册

在你与机器人的**单聊会话**里（首次需先发一条消息让对方找到你）：

```
① 给机器人发消息「审核」
   → 弹出「📋 审核工作台」卡片（顶部固定区，置顶）

② 卡片上 下拉勾选工作表（可多选，会列出表格内所有含「项目/回链」列的工作表）

③ 点「👀 仅预览」或「🚀 开始审核」
   → 系统发一张【独立的新卡】实时刷新进度（当前文件/行、通过/不通过计数）
   → 工作台卡保持不动，结果不盖掉入口

④ 审核完 → 结果卡展示：通过/不通过/已审跳过 数量 + 明细与不通过原因
   → 「仅预览」模式：到此为止，什么都不写
   → 正式模式：点「✔ 确认回写飞书表格」才写入；「✖ 放弃不写」则跳过

⑤ 想再来一轮：直接回点会话顶部那张「📋 审核工作台」卡重新勾选即可，无需重启机器人
```

补充行为：

- 机器人**每次启动**都会自动向会话推送/原位刷新工作台卡并置顶（不做就翻聊天记录找）
- 「🔄 刷新工作表」按钮：工作表结构变化后手动刷新下拉列表
- 跳过逻辑：某行「机器审核」列已有值 → 本轮跳过（增量补审友好）；「回链」列非 `.doc/.docx` 附件 → 跳过

## HTTP API 参考

`manage.py` 提供的接口（全部 `Content-Type: application/json`）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 返回面板页面（`panel/index.html`） |
| GET | `/api/state` | 运行状态 + 当前配置摘要（不含密钥） |
| GET | `/api/log?src=runtime\|audit&n=120` | 取日志尾部 N 行（`src=audit` 为当日审核日志） |
| POST | `/api/config` | 保存配置：`{spreadsheet, llm:{base_url,model,api_key,clear_api_key}, columns:{...}, forbidden_words}`（字段留空=不改） |
| POST | `/api/verify` | 用当前配置实测连一次飞书，返回工作表列表（连通性/授权校验） |
| POST | `/api/bot` | `{action: "start"\|"stop"\|"restart"}` 控制机器人 |

示例：

```bash
# 启动机器人
curl -X POST http://127.0.0.1:8788/api/bot -H "Content-Type: application/json" -d '{"action":"start"}'

# 换表格（贴完整链接自动解析）
curl -X POST http://127.0.0.1:8788/api/config -H "Content-Type: application/json" \
  -d '{"spreadsheet":"https://xxx.feishu.cn/sheets/XjS6sscu0hO98qtFkNqcV30YnKc"}'
```

## 常见问题 FAQ

**Q：点按钮/发消息机器人没反应？**
① 应用是否**已发布**（权限/事件改了必须发新版）；② 事件订阅是否选了「长连接」且两个事件都加；③ 看运行日志里的报错（面板日志 tab 或 `bot_runtime.log`）。

**Q：报「无权限」/ 列不到工作表？**
几乎都是漏了第 4 步——目标表格没把应用加为**可编辑**协作者。用面板「测试连接」一键复现并看报错。

**Q：结果没回写？**
「仅预览」模式本身不回写；正式模式需在结果卡点「✔ 确认回写」。另外确认应用对表格有可编辑权限。

**Q：工作台卡重复堆卡？**
不应发生：重启会先原位刷新旧卡（`workbench_state.json` 记录 message_id），旧卡删了才推新的。若手工把顶部卡删了，重启会推一张新的。

**Q：LLM 没生效？**
`api_key` 留空就是纯词库模式；配置后需**重启**；面板状态区会显示「未配 Key，已停用」。

**Q：为什么有的行不审？**
「回链」列非 `.doc/.docx` 附件（如抖音/淘宝链接、空值）按设计跳过；「机器审核」列已有值=已审过，增量补审会自动跳过。删掉该行「机器审核」的值即可重审。

**Q：要不要公网？**
不需要。bot 走飞书长连接（出站 WS），面板只监听本机。任何一步都不需要公网入站。

## 安全与隐私

- `config.yaml`（含 `app_secret` / `api_key`）已被 `.gitignore` 排除，**请勿提交到任何仓库**；发布时用 `config.example.yaml` 模板
- `cache/` 存放下载的**待审业务文档**与 LLM 缓存，属业务数据，同样不入库
- 面板仅监听 `127.0.0.1` 且无鉴权——不要把面板端口暴露到公网；如确需远程访问，请自行加反向代理与鉴权
- API 不回传已存密钥，只回 `api_key_set: true/false`
